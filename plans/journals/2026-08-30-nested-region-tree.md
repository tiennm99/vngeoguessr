# Nested region tree

Replaced the flat five-city model with a country>province>district tree (VN > HN/DN/TPHCM/LD/LA > 61 leaves) whose scores roll upward; every existing leaderboard point preserved. Pre-2025-merger admin extents kept deliberately (post-merger TPHCM spans 36,566 km2 - unguessable vs 1km scoring bands); Duc Hoa under Long An, not Tay Ninh. Guess resolves to leaf, credits leaf+province+VN; any node playable; country draws pick a province first. Generated tree from scripts/build-region-boundaries.mjs; TPHCM-CUCHI kept as unresolved (no OSM boundary relation) - absent coverage is data.
